# Stand Kit

Расширение Chrome: пульт дев-стендов в боковой панели. Сотрудники с логином и паролем, карты возможностей,
графики в любом из шести режимов, смены, учётки, раскатка и здоровье стенда — в пару кликов. Работает под
входами самого человека, отдельных паролей не нужно. Пишет только в дев-стенды, прод — только читает.

> Это витрина для портфолио. Гифки сняты на выдуманном стенде «qa-1 (демо)»: герои мультиков, телефоны
> +7 900 000-…, придуманные сервисы schedule, core, seeder и hiring. Рабочий код и установка — в закрытом
> репозитории команды: там адреса и ручки внутренних систем.

## Зачем

Чтобы проверить задачу, сначала нужны данные: нанять курьера, выдать ему карты на неделю, рассчитать график,
открыть смену, понять, почему упал под. Раньше это несколько админок, запросы руками, база и kubectl. В панели —
вкладка и кнопка, а ошибки объяснены человеческим языком.

**Ещё вкладки:** «Адаптация» — прогресс курсов обучения, как его покажет МО; «Зарплата» — засев прошлых смен
и заказов для отчёта «Заработная плата»; «Найм» — план найма на месяц: создать, финализировать, сдвинуть окно,
засеять все пиццерии.

**Шапка:** стенд и его занятость, подразделение и пиццерия, логи, версия и ↻. Строка «Входы» — точки МО,
Менеджера смены, админки и помощника. Сторож раз в 5 минут перепроверяет входы и продлевает вход в МО,
а слетевший вход восстанавливает сам фоновой вкладкой.

**Клавиши:** Alt+1…9 — вкладка, Alt+0 — настройки, / — поиск, Esc — закрыть, ? — список. Работают по месту,
а не по букве: на русской раскладке так же.

## Как устроено

- **Оболочка — расширение Chrome Manifest V3.** Боковая панель с рамкой и relay запросов: у оболочки есть права
  на домены стендов и куки входов пользователя, поэтому интерфейсу не мешает CORS. Правила declarativeNetRequest
  снимают чужой `Origin` там, где сервис его не пускает. Оболочка меняется редко.
- **Интерфейс — чистый JavaScript без фреймворков,** грузится в рамку с GitHub Pages: открыл панель — уже свежая
  версия, без переустановки. Логика вынесена в чистые модули без сети и DOM, детали вида — в общий набор
  (светофор, ящик, карточка действия, подтверждение).
- **Помощник на Python** — для «Стенда», раскатки и копии с прода. Слушает только `127.0.0.1` и только Origin
  расширения, выполняет kubectl правами самого человека. Секретов в расширении нет: env с похожими на секрет
  значениями приходит маской с отпечатком. Упал — сам заводит issue с отчётом, пароли и токены вырезаны.
- **Реестр фич:** каждая кнопка и запрос описаны в одном месте — отсюда «Мои фичи» и справка.
- **Справочник ошибок:** известные ошибки стенда и баги — с причиной и тем, что делать.
- **Обновления:** оболочку и помощник — по жёлтой полосе «обновите»; оболочку обновляет кнопка в самой полосе.

## Тесты

570 тестов на встроенном `node:test` и 132 на `unittest` для помощника, прогон в GitHub Actions на каждый PR.
Тест считается готовым, когда его видели красным: сломать логику — упал, вернуть — зелёный.

Гифки этой витрины сняты Playwright на настоящем интерфейсе: ответы стенда подменены выдуманными, а текст
каждого кадра прогнан через распознавание и проверен на внутренние адреса и имена.
